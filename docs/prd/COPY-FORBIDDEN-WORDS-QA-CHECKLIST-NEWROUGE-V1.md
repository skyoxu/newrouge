# NewRouge v1 文案禁用词 QA 自检清单（v1）

用途：给 QA/内容作者一份“1 页就能扫完”的禁用语境清单，避免把不存在的系统概念或可被滥用的语境带进 v1：
- 暗示“退出重进可以刷结果”
- 暗示“战斗中断点续打/从中途继续”
- 把商店写成能升级（v1 禁止）
- 把升级写成可反悔（v1 U1 不可逆；Ultimate 不可逆）

约束声明：
- 本文档只做文档规格与自检清单，不做任何代码实现/dev 操作。
- 本文档不创建任何 `docs/contracts/**` 类型的契约文件。

- 术语与按钮文案表：`docs/prd/TERMS-AND-COPY-GLOSSARY-NEWROUGE-V1.md`

## 0) 快速自检流程（v1）

1) 先扫“硬禁用语境”（出现即 P0）：见 1)  
2) 再扫“高误导词”（出现需确认语境并替换）：见 2)  
3) 最后检查四处高风险屏：MainMenu/Continue、Reward（三选一）、Upgrade、Shop（见 3)）  

验收原则：凡是玩家可见文本（UI、教程、事件、奖励、失败/错误提示）都必须遵守。

---

## 1) 硬禁用语境（出现即 P0）

### 1.1 刷结果语境（退出重进）

- 禁用：`退出重进可以换结果` / `退出刷新` / `重开刷新` / `刷奖励` / `刷事件` / `重抽` / `刷新候选`  
  替代：`候选已锁定（退出不会刷新）。`

### 1.2 战斗中断点续打语境

- 禁用：`从中途继续` / `从上一回合继续` / `战斗中断点续打` / `保存中间态`  
  替代：`继续后回到战斗初始状态。`

### 1.3 商店升级语境（v1 禁止）

商店内以下词一律禁用（即使实现上有别的服务，也不能让玩家理解为升级）：
- 禁用：`升级` / `升星` / `进阶` / `强化` / `改造`  
  替代：`购买` / `移除` / `转换` / `重铸`（按实际服务选用）

### 1.4 升级可逆语境（v1 禁止）

- 禁用：`可反悔` / `可撤销` / `随时能改回`（用于 U1/Ultimate）  
  替代：`选择后不可逆。` / `不可逆。不可再升级。不可换路线。`

---

## 2) 高误导词（需确认语境后替换）

- `随机`：可以描述“候选生成”，但必须同时强调“候选集已锁定”与“可复现”口径；避免把它写成可刷。
- `重置`：仅用于天赋树（共享且可无条件重置）；不得用于卡牌升级（U1 不可逆）。
- `强化`：可以用于“天赋/规则/权重”语境，但不得出现在商店 UI；也不得让玩家误以为可对已升级卡随时反悔。

---

## 3) 四个高风险界面（必查点）

### 3.1 MainMenu/Continue

不得出现：
- “Continue 会恢复到战斗中途”的暗示
- “新游戏自动覆盖且不可取消”的暗示

必须明确：
- `继续游戏` 读取单槽 autosave
- 覆盖确认默认焦点为 `取消`

### 3.2 Reward（三选一/多选一）

不得出现：
- “退出后可能出现不同候选”的暗示

必须明确（短句即可）：
- `候选已锁定（退出不会刷新）。`

### 3.3 Upgrade（U1/路线重选/Ultimate）

不得出现：
- 把 U1 写成可反悔
- 把 Ultimate 写成还能继续升级或还能换路线

必须明确：
- U1：二选一不可逆
- 路线重选事件：事件内可随意切换，但离开定稿
- Ultimate：不可逆、不可再升级、不可换路线

### 3.4 Shop（商店）

不得出现：
- 任何升级语境（包括“强化/进阶/升星/改造”等）

## 4) 文档自检（Windows）

```powershell
rg -n \"刷新|重抽|刷奖励|战斗中途|断点续打|商店.*(升级|强化|进阶|升星)|可反悔|可撤销\" docs
```
