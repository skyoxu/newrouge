# NewRouge 60 分钟试玩脚本与记录表（v1）

用途：把“v1 体验结构是否仍然成立”变成可复用的试玩流程与记录表，用于进入 game-design 内容量产前后快速验证：
- 单槽 autosave + Continue 的边界是否清晰且不误导
- 退出重进不刷结果是否成立（候选集锁定）
- 升级系统的不可逆提示是否清晰（U1/Ultimate），以及路线重选事件是否不误导
- 商店是否严格无升级语境

约束声明：
- 本文档只做文档规格与试玩流程，不做任何代码实现/dev 操作。

## 1) 60 分钟流程（建议顺序）

### 1.1 0–10 分钟：MainMenu → 新局/覆盖确认 → 难度 → 角色 → 路线图

目标：
- 覆盖确认默认焦点=取消（避免误操作）
- 难度说明不误导为“强绑定天赋树”

必须观察并记录：
- 主菜单是否出现“多槽存档/云同步/可刷结果”的暗示（v1 禁止）
- 覆盖确认是否清晰写明“不可撤销”

### 1.2 10–25 分钟：进入事件/奖励（三选一）并做一次“退出重进不刷”验证

目标：
- 三选一候选集锁定成立：退出到主菜单 → Continue → 候选集与顺序一致

步骤（动作 / 预期）：
1) 在某个节点触发三选一奖励界面（来源不限：事件/战斗/结算）
2) 记录当前候选项的 3 个名称（截图或手抄）
3) 退出到主菜单（或强制退出应用）
4) 点击 `继续游戏`
5) 回到同一奖励界面后对比候选项与顺序

Pass 判定：
- 候选项与顺序完全一致
- UI 文案不暗示可刷新候选

### 1.3 25–40 分钟：休整节点升级（U1 二选一不可逆）

目标：
- 休整升级明确“免费升级 1 张卡牌”
- U1 Route A/B 二选一不可逆（离开升级入口后不可反悔）

必须观察并记录：
- 升级界面是否明确写了“选择后不可逆”
- 是否把“路线重选事件”与“天赋树重置”混在同一语境里（应避免）

### 1.4 40–50 分钟：商店节点（验证“无升级语境”）

目标：
- 商店内不存在升级入口/按钮/同义词误导

必须观察并记录：
- 是否出现“升级/强化/升星/进阶/改造”等禁用语境
- 退出商店返回路线图是否顺畅（不死链）

### 1.5 50–60 分钟：战斗中退出重进（回到战斗初始状态）

目标：
- 战斗中退出后 Continue 只回到战斗初始状态，不存中间态

步骤（动作 / 预期）：
1) 进入一场战斗并执行至少 1–2 个动作（产生中间态）
2) 退出到主菜单或强退
3) Continue
4) 验证战斗状态回到初始（而非中间态）

Pass 判定：
- 回到战斗初始状态
- UI/文案不出现“从中途继续”语境

## 2) 关键体验门禁（本脚本“必须通过项”）

1) 覆盖确认：默认焦点=取消；文案明确不可撤销  
2) 候选集锁定：退出重进候选不变（含顺序）  
3) 升级提示：U1 不可逆；Ultimate 不可逆且不可换路线  
4) 商店无升级语境：禁用词清单 100% 通过  
5) 战斗退出重进：只回到战斗初始状态
