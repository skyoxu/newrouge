This can retain observations across an exec-channel disconnect; it cannot promise survival of every host/process failure. No product, original guard, reader3600, Job, NX/public scope lock or original host entry is modified. No outer timeout, kill, Job or lock is added. Launcher exit0 means only launched, never native/test PASS.

```powershell

The launcher checks the new launch, supervision and worker-output namespaces are absent; creates exclusive launch01 intent; uses Start-Process -WindowStyle Hidden -PassThru with separate supervisor stdout/stderr files; and records returned supervisor PID/birth or uncertain launch failure. Never retry any existing/uncertain namespace automatically. It deliberately returns without waiting on the exec channel. Root must inspect the original supervisor/worker records later.
