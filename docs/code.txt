Knowledge Control Plane Impact Analysis（知识控制面影响分析层）

Knowledge Control Plane Impact Analysis Requirements
1. Overview
Requirement ID
KCP-IMPACT-001
Type
Platform Capability
Priority
P1
2. Background

Newrouge 已完成 Knowledge Control Plane 迁移：

已有能力：

Task
 |
Acceptance
 |
ADR
 |
Contract
 |
Decision
 |
Freeze

可以回答：

为什么修改？

但是 AI 游戏开发过程中仍存在另一类问题：

修改一个代码对象，会影响什么？

例如：

修改：

Game.Core/Contracts/RewardOfferPresentedEvent.cs

Knowledge Control Plane 可以知道：

ADR-0032
ADR-0033
GM-0129

但是无法回答：

哪些系统消费这个 Event？

哪些测试依赖？

哪些 Scene 使用？

哪些 Runtime flow 会变化？
3. Goal

建立一个轻量级 Impact Analysis Layer。

目标：

让 AI 在编码和 Review 前获得：

Change Target
       |
       v

Affected Surface

       |
       +-- Code
       |
       +-- Tests
       |
       +-- Runtime
       |
       +-- Knowledge
4. Non Goals

本需求明确不实现：

❌ Full CodeGraph

不实现：

Class graph
Method graph
Call graph
AST database

原因：

成本高，且不是当前瓶颈。

❌ Replace Knowledge Control Plane

Impact Analysis 不决定：

Authority
Architecture
Design
Acceptance

这些仍由：

ADR
Task
Freeze
Decision

负责。

❌ Autonomous Refactoring

不会自动修改代码。

只提供：

Impact Evidence
5. Core Concept

新增：

Impact Context

类似：

Knowledge Context

但是回答：

What changes if this changes?
Context Example

输入：

Game.Core/Contracts/RewardOfferPresentedEvent.cs

输出：

{
 "target":
 "Game.Core/Contracts/RewardOfferPresentedEvent.cs",

 "impact": {

   "code_consumers":[
      "RewardService",
      "RewardUI"
   ],

   "tests":[
      "Task0029AcceptanceTests",
      "CardPoolSelectionTests"
   ],

   "runtime_flows":[
      "Reward Offer Flow"
   ],

   "knowledge_refs":[
      "ADR-0032",
      "ADR-0033"
   ]
 }
}
6. Functional Requirements
FR-001 Target Resolution

系统必须支持：

输入：

file
class
interface
event
contract
scene
resource

例如：

RewardOfferPresentedEvent

解析为：

Game.Core/Contracts/Events/
RewardOfferPresentedEvent.cs
FR-002 Symbol Impact Detection

系统应该发现：

Direct References

例如：

RewardOfferPresentedEvent

被引用:

RewardService
RewardUI
Tests
Contract Dependency

例如：

interface IRewardProvider

影响：

RewardProviderA
RewardProviderB
FR-003 Test Impact Mapping

支持：

代码：

RewardService

映射：

Tests:

RewardServiceTests

Task0029AcceptanceTests

CardPoolSelectionTests
FR-004 Runtime Impact Mapping

针对游戏项目：

支持：

C# code
        |
        |
Godot scene
        |
        |
Node
        |
        |
Signal

例如：

RewardPanel.tscn

connects

RewardOfferPresentedEvent
FR-005 Knowledge Binding

Impact Analysis 必须关联 Knowledge Control Plane。

输出：

例如：

{
 "knowledge_refs":[

 {
   "type":"ADR",
   "id":"ADR-0032"
 },

 {
   "type":"TASK",
   "id":"GM-0129"
 }

 ]
}
FR-006 Change Risk Classification

输出风险：

{
 "risk":"high"
}

规则：

High:

Contract change
Event change
Save format change
Core domain change

Medium:

Service change
System change

Low:

UI only

9. Authority Rules

必须遵守：

Impact ≠ Authority

例如：

Graph:

A calls B

不代表：

B is architecture authority

Authority 仍来自：

ADR

Task
Decision
