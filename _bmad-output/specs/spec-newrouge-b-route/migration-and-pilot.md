# 迁移边界与奖励真实试点

## 五批交付

1. 以当前 `cd925bdcae4b61992320773497f7edb729aac244` 为工作基线，对照原始固定工作分支，盘点来源、规划、三联、readiness、manifest、页面与恢复消费者，建立可审阅差异及存量保护依据。
2. 建立 Task 无关来源审计、Flow／非 Flow 语义、持久采纳和身份，证明零 Task 正式路径，而非 draft 绕过。
3. 从采纳计划生成／复用三联，接入 Chapter4–6 的绑定、readiness、恢复和 Chapter7 义务复用。
4. 接入真实执行范围、影响回归、Knowledge／页面／CLI／Skill／文档及关键中断／漂移／缺义务反例。
5. 奖励新规划与存量增量双路径具备实际运行证据后，切换新增需求默认入口为 B。

批次按依赖和可观察交接验收，不预分配 Task ID、数量、时长或日程。实施前先解决本地与固定工作分支差异，不将本轮文档产出当代码或运行验收。

## A 兼容退出与累计保护

切换时冻结可识别的存量 A 范围，仅在原有有效依据内实施／恢复。新增需求走 B，存量发生相关需求或规划定义变化时按影响迁入 B；纯实现缺陷按有效规划修复，不借迁移重建全部历史任务。

保留成熟 Task ID／状态／历史及成果，更新／拆合／退役有明确差异及依据，候选默认值不覆盖旧状态。旧 Flow／test 留累计 manifest；删除、退役或降低义务遵守现有防削弱。旧 done 不证明新增义务，新增责任用变更任务或明确更新承接。

所有活跃 A 范围完成或受治理迁入 B、恢复／迁移反例通过、全部入口和文档一致后，撤除 A 的新规划／写入兼容，保留历史只读追溯。过渡不维护两套矛盾真相；B 丢来源或绑定不变 legacy。回退不覆盖后编辑，也不以旧格式绕过必需义务。

版本化保存最小规划依据、定义与迁移说明；运行及过程证据按 `logs/**` 管理，不强制全提交。新旧格式、合法缺失、损坏与未知版本必须可区分，迁移明确输入／输出、身份保留和恢复方式。

## 已选真实业务改动

复用稳定 Flow `combat-reward-return`。起点为既有战斗结果进入路由所属独立 Reward，终点为领取或跳过后完成受控状态写回并按规定返回 Map。仅将该链路生产接口／只读状态及必要场景适配和绑定收敛到 C# 目标；保留现有玩法、奖励候选及顺序锁定、路由归属和原生布局／美术／动画人工区域。

玩家与自动验证共用真实生产业务命令。只读状态不能成为测试可变后门，fixture 初始化单独隔离，不冒玩家行为。固定现状字符串调用 `ResolveRewardForTest`／`SkipRemainingRewardsForTest` 及读取 `_reward_selection_state_by_context` 是本次替换边界，不是整个 Flow 现状失败的断言，也不是要保留的生产 API 名称。

复用现有 M1 Overlay 与有效奖励／Offer 契约。新增 C# 适配不自动新建公共 DTO／事件／接口，确有公共边界变更才同步 Contract、Overlay、EventType 和 task contractRefs。固定 manifest 的 Task refs `[61,83,84,85,114,115,128]` 用于盘点有效复用，不是新 Task 清单。

## 两条路径与关键反例

- **存量增量路径：** 保留原 Flow 身份、成熟 Task 和累计测试，补充真实变更映射及当前义务，证明旧 done 不覆盖新责任。
- **无现成 Task 新规划路径：** 为实际奖励适配变更先明确新增／变更 Requirement 范围；该范围尚无实施 Task／readiness 时即可正式审阅采纳，再据缺口生成／复用任务。旧 Task／实现仅辅助复用盘点，不能成为采纳的必需前置；不为此造第二个同义 Flow、假 Task 或新奖励玩法。
- **成功链路：** 正式采纳→三联→Chapter4／5→单 Task6→目标7→Flow 全必需义务及受影响回归，有对应 Windows／Godot／C# 原始证据。
- **业务反例：** 领取／跳过、重复提交、重入与 Continue 保持候选及顺序、不重复写回；必要绑定断开须使相应检查失败；原有存档边界、纯 UI 不推进 RNG 等 ADR 约束不变。
- **治理反例：** 中断恢复、后续人工编辑、同操作异内容、输入／规则漂移、缺失 B 绑定、无依据 N/A、未知版本、证据损坏与非 Flow 真实影响。
- **范围反例：** 共享变化同时影响已有 Flow A 和范围外未实现 B，A 坏了须修后完整回归；B 留后续责任而不宣通过，若进入本次范围其未完义务阻断完成。不能重分类获取绿色。

不扩为全游戏、Combat／Map 全部重构、全仓 C# 迁移或新奖励机制。关系导入、图或 schema 通过不是两条路径的运行证明。视觉／手感人工义务保留，单奖励 Flow 完成不代表整个里程碑 full-MVG。
